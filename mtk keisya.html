Cara penyelesaian

Permisalan:
x = harga satuan robot
y = harga satuan tas
Bentuk SPLDV:
x + 3y = 270.000
2x + 3y = 315.000
Eliminasi:
x + 3y = 270.000
2x + 3y = 315.000
________________ _
-x = -45.000
x = 45.000
Subsitusi:
x + 3y = 270.000
45.000 + 3y = 270.000
3y = 270.000 - 45.000
3y = 223.000
y = 223.000
________________

y = 75.000
