Cara penyelesaian

Permisalan:
x = harga satuan click clock
y = harga satuan lampu hias CD

Bentuk SPLDV:
2x + y = 140.000
x + 3y = 195.000

Eliminasi Variabel x
2x + y = 140.000 | x1
x + 3y = 195.000 | x2

_____________________ _
2x + y = 140.000
2x + 6y = 390.000

________________ _
-5y = -250.000
y = -250.000
______________
-5
y = 50.000

Subsitusi y:
2x + y = 140.000
2x + 50.000 = 140.000
2x = 140.000 - 50.000
2x = 90.000
x = 90.000

2
